# 🎨 ArtBhavan – Your Art Journey Begins Here!

> [!IMPORTANT]
> **Status:** This website is currently not deployed and is under active maintenance. Development is ongoing.

**ArtBhavan** is a modern, feature-rich art marketplace built with Django. It provides a platform for art enthusiasts to explore, discover, and collect beautiful artworks ranging from sketches and portraits to digital art and oil paintings.

---

## 🌟 Key Features

### 🛍️ Art Marketplace
- **Curated Collections:** Browse through various categories like Sketches, Portraits, Oil Paintings, and Digital Art.
- **Detailed Artwork Views:** View artworks with multiple thumbnails, detailed descriptions, and high-quality images.
- **Shopping Cart:** Add your favorite pieces to the cart and manage quantities easily.
- **Checkout & Orders:** Secure checkout process with order history and status tracking.

### 👤 User Experience
- **Smart Profiles:** Personalized user dashboards to manage profile details, addresses, and order history.
- **Authentication:** Secure signup, login, and password reset workflows (with email integration).
- **Responsive Design:** A premium, mobile-first design that looks stunning on all devices.

### 📧 Notifications
- **Automated Welcomes:** Instant email confirmation upon signing up.
- **Order Updates:** Stay informed with automated notifications for order placements and status changes.

---

## 🛠️ Tech Stack

- **Backend:** [Django 5.x](https://www.djangoproject.com/) (Python)
- **Database:** SQLite (Default for development)
- **Frontend:** HTML5, Modern CSS3, JavaScript (Vanilla)
- **Icons & Assets:** Custom branding with localized assets
- **Dependencies:** `django-countries` for address management
